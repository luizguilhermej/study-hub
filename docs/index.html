Projeto em dupla∿

Gêmeo digital térmico de um dissipador para GPU

Como a geometria e os materiais de um dissipador — base de cobre e aletas de alumínio — influenciam a temperatura de uma NVIDIA GeForce RTX 4060 sob carga térmica contínua?

PythonEnergy2DFreeCADGitHub

Entregas do projeto

  • Código Python com diferenças finitas
  • Simulação e validação no Energy2D
  • Modelo CAD e desenho técnico
  • Relatório em formato ABNT e vídeo de demonstração
Aprendizados

O trabalho envolve representar a transferência de calor por diferenças finitas e comparar a modelagem em Python com a simulação no Energy2D. Também integra modelagem CAD, desenho técnico e documentação acadêmica em um fluxo de projeto compartilhado.
